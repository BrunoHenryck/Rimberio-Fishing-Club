# 🎣 Rimberio Fishing Club – Página de Links

Este repositório contém o código-fonte de uma **página de links estilo Linktree**, desenvolvida para o **Rimberio Fishing Club**, com o objetivo de centralizar e facilitar o acesso às principais informações do negócio.

A aplicação é **simples, leve e responsiva**, ideal para uso em redes sociais, QR Codes ou como página inicial de divulgação.

## 🔗Link para acesso

https://brunohenryck.github.io/Rimberio-Fishing-Club/

---

## 📌 Funcionalidades

* ✅ Página de links moderna e responsiva
* ✅ Botões de acesso rápido para:

  * Cardápio
  * WhatsApp
  * Localização
* ✅ Layout escuro com identidade visual personalizada
* ✅ Estrutura limpa e fácil de modificar

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** – estrutura da página
* **CSS3** – estilização e responsividade
* **JavaScript** – interações básicas

> Projeto 100% front-end, sem dependências externas.
